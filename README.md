# ComfyUI-FaceBeauty · 综合美颜精修节点

一个纯本地的 ComfyUI 美颜节点：皮肤级磨皮/美白/锐化 + mediapipe 478 关键点面部微整形，支持**多人脸**同框处理。

不依赖任何在线服务，不需要额外的 GPU 训练模型，显存占用可忽略（OpenCV + mediapipe CPU 推理）。

## 功能

**皮肤级美颜**（只作用于皮肤遮罩，不碰头发/背景/衣服）

- 磨皮：双边滤波，保边去噪
- 美白：YCrCb 亮度通道提亮，**色度不变**，不发灰；遮罩包含脸部核心区（FaceOval ∩ 肤色）+ 颈部/肩颈延伸区，避免脸白脖子黑的断层
- 锐化：USM 锐化（全图，让五官更清晰）

**面部精修**（局部形变，羽化衰减不伤背景）

- 瘦脸、大眼、微笑
- 牙齿美白（仅嘴内亮而低饱和像素）
- 自动摆正头部（按双眼连线水平矫正，带方向自检）
- 头部左右转 / 上下仰（2D 透视近似，局部混合）
- 眼球左右 / 上下

## 安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/liyebin520555/ComfyUI-FaceBeauty.git
```

依赖（ComfyUI 环境里缺哪个装哪个）：

```bash
pip install mediapipe opencv-python numpy
```

`models/face_landmarker.task` 已随仓库提供（mediapipe 官方 face landmarker 模型，478 点，`num_faces=5`）。

启动 ComfyUI 后节点位于分类 **美颜精修**，显示名 `✨ 综合美颜精修（皮肤级·面部形变）`。

## 参数

| 参数 | 范围 | 说明 |
| --- | --- | --- |
| 图像 | IMAGE | 输入图像，支持批量 |
| 磨皮 | 0–100 | 双边滤波磨皮，只作用于皮肤区域 |
| 美白 | 0–100 | YCrCb 亮度提亮，覆盖脸部与颈部皮肤，建议 30–50 起步 |
| 锐化 | 0–100 | USM 锐化，全图 |
| 自动摆正头部 | 开关 | 按第一张脸的双眼连线做水平矫正 |
| 瘦脸 | 0–100 | 两侧脸颊向中轴收窄 |
| 大眼 | 0–100 | 以眼心为圆心径向放大 |
| 微笑 | 0–100 | 两侧嘴角向上向外轻推 |
| 牙齿美白 | 0–100 | 仅嘴内亮而低饱和像素提亮降饱和 |
| 头部左右转 | -50–50 | 正值向观众视角右侧转 |
| 头部上下仰 | -50–50 | 正值抬头、负值低头 |
| 眼球左右 / 上下 | -50–50 | 眼周内容位移，视觉上像转动视线 |

## 说明

- **汉化**：控件名本身即为中文，同时提供 `locales/zh/nodeDefs.json` 标准语言包，界面语言切换到中文时同样显示中文。
- **多人脸**：最多同时处理 5 张人脸，各自独立做形变与美颜。
- **鲁棒性**：未检测到人脸时原图返回；处理过程中出现任何异常也原图返回，不会中断队列。
- 形变幅度随人脸尺寸自适应（按瞳距/脸宽计算半径与位移）。
